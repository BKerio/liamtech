# LiamTech Auto Spare Parts

LiamTech Auto Spare Parts is a simple online store for selling quality automobile spare parts. Customers can browse products, check vehicle fitment, add items to the cart, and place orders for parts they need.

## What we sell

- Engine and mechanical parts
- Brake and suspension parts
- Electrical and lighting parts
- Body and interior accessories
- Filters, oils, and maintenance supplies

## Features

- Product catalog with categories
- Search and filtering for fast browsing
- Vehicle compatibility lookup
- Shopping cart and checkout process
- Admin tools for managing products, orders, and stock

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 or view online on https://liamtech.vercela.pp in your browser.

## Technology

This project is built with Next.js, Prisma, and Neon Postgres for a modern storefront experience.

## Purpose

The goal is to make it easy for drivers and repair shops to find the right auto spare parts quickly and order them online with confidence.
